# Mapas de Coldwell Banker Zetaté

Propiedades de Coldwell Banker Zetaté sobre mapa satelital, barrio por barrio.

- **Portada:** https://coldwellbankerzetate.github.io/
- **Un barrio:** `https://coldwellbankerzetate.github.io/<barrio>/` (ej. `/pueblo-mio/`, `/la-juanita/`)
- **Selección para un cliente:** guardá casas con el corazón y tocá "Mi selección"; ahí se arma el link para compartir.

Se actualiza solo todos los días con lo que está publicado en Tokko. Para actualizar al instante:
pestaña **Actions → Sincronizar con Tokko → Run workflow**.

Detalle técnico para editar: ver `CLAUDE.md`.

Imagen satelital: Esri, Maxar, Earthstar Geographics.
